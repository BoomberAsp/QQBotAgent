Lucima QQ 使用手册

在群里先 @ 机器人，私聊可以直接发命令。阅读手册无需登录游戏。

快速开始

/lucima 大厅打开操作菜单

/lucima 登录获取网页登录入口

/lucima 状态查看任务进度

登录

私聊发送 /lucima 登录。在群里先 @ 机器人。打开机器人发来的二维码或网页登录链接，按网页提示在发起登录的会话发送核对命令。群里的核对命令由发起人发送，密码只在网页填写。

绑定成功后会在原会话收到大厅和账号信息卡。私聊显示完整卡，群聊默认显示精简卡。群内可由发起人点击「展开详情」并确认。

临时授权有效 15 分钟，选择「记住登录」可保存最长 30 天，并用于每日托管。已保存授权失效时可重新扫码。授权成功后可以用 /lucima 刷新信息 登录游戏查看快照。

从大厅的「切换账号」可添加或切换本会话的账号，也可发送 /lucima 切换账号 2。同一游戏账号只能绑定一个 QQ 会话的一个账号槽。改到其他群或私聊使用前，先在原会话发送 /lucima 解绑 并确认。退出当前账号可在大厅操作，退出后该账号的托管暂停。

查询

/lucima 刷新信息连接游戏并重新生成账号信息卡

/lucima 查看资源查看体力、钻石等资源

/lucima 查看团员 1查看团员和角色 ID，可在页码后加名称

/lucima 查看物品 1查看物品列表，可在页码后加名称

/lucima 查看队伍 1查看已保存的队伍和队伍 ID

/lucima 查看团概况查看佣兵团状态

/lucima 查看团周任务查看佣兵团周任务

/lucima 筛装备 [套装名]按副属性分数查看装备

/lucima 图鉴 夏妮查询公开角色图鉴，无需登录

账号查询会临时连接游戏。在群里发起的查询结果会显示在原群。

日常

从大厅进入「自动任务」可以找到日常领取入口，也可以直接发送下面的命令。

/lucima 签到检查并领取可领的签到奖励

/lucima 领邮件领取邮件附件

/lucima 领基地检查动力转换、成长药剂和升星水晶

也可单独发送 /lucima 动力转换、/lucima 成长药剂、/lucima 升星水晶 或 /lucima 技能模块。

其他常用命令有 /lucima 每日体力、/lucima 领派遣、/lucima 领成就、/lucima 免费招募、/lucima 团签到、/lucima 团周奖 和 /lucima 兑换 <兑换码>。领派遣只领取已完成的奖励。

执行前核对确认卡，点「确认执行」或发送卡片上的 /璐茜玛 执行 <编号>。游戏冷却、开放时段、可领取额度等条件仍然适用。

托管

网页授权时勾选「记住登录」。按账号和任务分别设置计划，例如 /lucima 托管 动力转换 20:00。核对确认卡后，每天北京时间 20:00 起可以排队执行一次。也可在「自动任务」里打开具体任务设置。

/lucima 托管状态查看当前账号的计划和最近托管回执

/lucima 停止托管 动力转换确认后停止该任务

/lucima 停止托管确认后停止当前账号的全部托管

QQ 端按托管时间入队。网页授权、刷新信息和手动执行一次均不会自动运行其他任务。每日计划在设定时间后的一小时内参与排队。若执行时领取条件还未满足，本次跳过，达到条件时不会补跑。账号退出后托管暂停，授权失效时无法执行。

商店

/lucima 刷新秘密商店 1 免费 目标=无只刷新和筛选，免费额度可用时最多刷新一次

/lucima 刷新秘密商店 <次数> 钻石 [方案名]次数 1–200，确认前核对本次报价和扣款上限

秘密商店手动刷新可按确认卡列出的目标自动购买普通道具。命令末尾可加 目标=招募契约,神秘契约 或 目标=无。

/lucima 查看星源商店查询星源商店刷新计数

/lucima 刷新星源商店 <次数> <方案名>按确认卡上的报价和条件执行，报价不可核实时不会提交

商店命中装备后，先看回执中的装备档位、数量和价格，再按原结果卡选择购买或结束本轮。

/lucima 长任务查询 商店查询批量购买参考报价

/lucima 批量购买 <商品ID:数量:货币ID:单价>多项用空格隔开，确认前核对价格和总额

/lucima 查看团店查询团员商店的商品、价格与限购

/lucima 购买团店 <商品ID> <数量> <货币ID> <单价>按当前团员商店货架报价购买

装备方案

装备方案按当前账号保存，可用于商店刷新筛选。在大厅进入「工具箱 → 装备过滤」，或发送以下命令。

/lucima 保存装备方案 {"name":"速度戒指","slots":{"ring":[{"sets":["Speed"]}]}}新建或导入方案

/lucima 预览装备方案 速度戒指查看当前背包中的命中结果

/lucima 导出装备方案 速度戒指导出 JSON 供复制和修改

/lucima 复制装备方案 速度戒指 备用复制现有方案

/lucima 删除装备方案 备用确认后删除该方案

战斗

/lucima 讨伐关卡 [属性|关卡ID]查看通关状态和扫荡体力参考价，例如 /lucima 讨伐关卡 火

/lucima 元素关卡 [属性|关卡ID]查看通关状态和扫荡体力参考价，例如 /lucima 元素关卡 水

/lucima 查看幻境查看虚拟幻境最高通关层和意识同步器

/lucima 幻境扫荡查询当前扫荡条件，点击「准备扫荡」后由发起人在原会话确认

QQ 沿用第 80 层的扫荡门槛。游戏会消耗全部意识同步器，体力消耗 0。也可发送 /lucima 幻境扫荡 <同步器上限>。

/lucima 活动推进查看可推进活动、下一关体力标价与可用队伍 ID

/lucima 活动推进 <活动ID> <队伍ID> <最多关数> <体力上限>最多 3 关，按确认的范围推进

/lucima 长任务查询 活动扫荡 [活动ID|关卡ID]查看当期已通关活动的扫荡体力参考价。三类付体力扫荡待接入。

/lucima 虚构深渊查看可挑战楼层。用 /lucima 查看团员 1 查角色 ID

/lucima 虚构深渊 <关卡ID> <上半角色列表> <下半角色列表>发起单层挑战，体力上限 0。队内角色 ID 用逗号分隔，空位填 -。

可点查询结果中的活动或楼层，补齐参数后发送。由发起人在原会话确认，也可以用 /lucima 取消 或 /lucima 回执。

也可从大厅查看竞技场、活动投票、装备活动和佣兵团援助等状态。详情页会标明 QQ 端支持的操作。

回执

/lucima 状态查看进度或排队状态

/lucima 回执 [编号]取回最近回执或指定回执

/lucima 任务历史 [页码]浏览当前账号的任务记录

/lucima 取消取消排队任务或请求停止正在执行的长任务。已提交给游戏的操作以实际结算为准。

确认卡有效五分钟。群聊中由发起人在原群 @ 机器人发送卡片上的命令，或点原卡按钮。「本次没有可执行项目」表示本次任务跳过，例如动力转换的领取间隔未到。若收到「结果待核对」或「结果未知」，先查看游戏内记录，再决定是否重试。
