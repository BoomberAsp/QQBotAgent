它是谁

一个跑在 QQ 里的多模型智能体，而不是关键词复读机。

智能体循环

每条消息都经过「思考 → 行动 → 观察 → 回应」循环：先想该用什么工具，调用后阅读结果，再组织成回答。最多 20 轮工具调用，复杂任务也能拆解完成。

多模型路由

简单问题走快速模型秒回，复杂推理自动切换到强力模型；图片与语音另有专用多模态模型处理。你只管说话，路由交给它。

长期记忆与画像

三层记忆引擎自动从对话中提取事实：重复确认的会被强化记住，长期不用的逐渐衰减。聊过的事不用重复介绍第二遍。

三种人格

助手 Roxy、角色 Roxy、露比三种人格提示词驱动，/人格切换 即时切换，群聊还可由管理员绑定默认人格。

专属工作区

每个 QQ 号拥有独立文件空间（代码 / 上传 / 输出 / 项目子目录），按权限分配 100MB 至 2GB 配额，互不可见。

本地部署 · 隐私优先

基于 NoneBot2 + NapCat（OneBot V11）自建部署，文件操作全部限制在沙箱工作区内，对话数据仅本地存储、不用于训练。

使用说明

从零到熟练：怎么说话、怎么用命令、会话怎么管。

01

怎么开始对话

私聊：直接发消息即可，无需 @。群聊：发送 @Roxy + 内容 触发。

不需要记任何命令。搜索、翻译、天气、路线、查资料……像和朋友说话一样直接提需求，它会自己决定调用哪些工具。

02

群聊免 @ 窗口（连续对话）

在群里 @ 过它一次之后，会开启一个 90 秒的连续对话窗口：窗口内继续发消息不需要再 @，它会直接接话。

  • 每发一条消息，90 秒倒计时重新计满——只要聊得够快，窗口一直续着。
  • 90 秒内没人说话，窗口自动关闭，恢复「必须 @ 才理你」。
  • 想提前退出：发送 或 。
  • 窗口按「群 + 人」独立计算，你在 A 群的窗口不影响 B 群。
03

命令特殊符怎么输入

系统命令以半角斜杠 / 开头（如 /帮助），反馈类以半角井号 # 开头（如 #反馈）。规则只有三条：

  • 符号必须是消息的第一个字符，前面不能有空格或其他内容。
  • 必须用半角符号。全角的 ／ 和 ＃ 不会被识别，会被当成普通聊天内容交给 AI。
  • 命令由系统直接处理、不经过 AI、零 token 消耗，所以响应几乎即时；没命中命令的文本才会进入智能体循环。
04

临时会话 vs 特殊会话

这是两套完全独立的存储系统，不是同一系统的两种模式：

临时会话（默认）特殊会话（手动创建）
创建方式发消息即存在，无需操作/新会话 [名称] 创建，或 /保存为会话 <名称> 把临时对话存档
上下文容量只保留最近 20 条消息，更早的被挤掉完整上下文持久保存，长对话不丢细节
过期策略30 分钟不活跃自动过期清空永久保存，直到你 /删除会话
数量限制每人 1 个按权限：管理员 10 个 / VIP 3 个 / 普通 1 个
管理命令/clear 或发「新对话」清空重来/切换会话 /会话列表 /重命名会话 /删除会话 /结束会话
适用场景随口一问、短平快任务长篇项目讨论、攻略整理、需要隔天接着聊的内容

在特殊会话中发送 /结束会话（或 /临时会话）即退回临时模式，特殊会话本身不会被删除。

05
