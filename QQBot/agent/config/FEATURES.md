# 功能一览

本文档列出机器人的全部功能，按大类分组。发送 `/功能` 或 `/features` 即可在 QQ 中直接查看。

---

## AI 对话

| 功能 | 说明 |
|------|------|
| 智能问答 | LLM Agent 驱动，Think → Act → Observe → Respond 循环，最多 20 轮工具调用 |
| 多模型路由 | 简单问题用快速模型，复杂推理用强力模型，图片/音频另有专用模型 |
| 上下文记忆 | 临时会话保留最近 20 条消息，特殊会话支持百万 token 完整上下文 |
| 群聊连续对话 | @机器人一次后 5 分钟内可免 @ 继续追问，`/取消` 退出 |
| 人格切换 | 助手Roxy / 角色Roxy / 露比 三种人格，提示词驱动，`/人格切换` 切换；超级用户可 `/toggle personality <名称>` 为群聊绑定默认人格 |

## 直接命令一览

以下命令**直接由系统处理、不经过智能体**，零 token 消耗。

### 会话管理

| 命令 | 说明 |
|------|------|
| `/新会话 [名称]` | 创建特殊会话（留空自动命名） |
| `/切换会话 <名称>` | 切换到已有会话 |
| `/会话列表` 或 `/会话` | 查看所有会话 |
| `/重命名会话 <旧名> <新名>` | 重命名会话 |
| `/删除会话 <名称>` | 删除会话（60秒内二次确认） |
| `/保存为会话 <名称>` | 将临时对话保存为特殊会话 |
| `/结束会话` | 退出特殊会话，回到临时模式 |
| `/clear` 或 `清除上下文` | 清除临时会话上下文 |

### 人格 & 功能

| 命令 | 说明 |
|------|------|
| `/人格切换` | 查看当前人格和可用列表 |
| `/人格切换 <名称>` | 切换人格（支持模糊匹配，如「露比」「Rubi」） |
| `/功能` 或 `/features` | 查看完整功能一览（本表） |
| `/status` | 查看机器人运行状态 |

### 游戏 & 反馈

| 命令 | 说明 |
|------|------|
| `/兑换码` 或 `/redeem-code` | 查询有效兑换码（自动刷新） |

### 群管理（仅群聊 + 超级用户）

| 命令 | 说明 |
|------|------|
| `/toggle` | 查看当前群功能开关状态与默认人格 |
| `/toggle <功能> <on|off>` | 开关功能（gacha / image / voice） |
| `/toggle personality <名称>` | 设置本群默认人格（模糊匹配） |
| `/toggle personality 默认` | 清除本群默认人格，回落全局默认 |

### 反馈

| 命令 | 说明 |
|------|------|
| `#反馈 <内容>` | 提交功能建议（附上下文快照） |
| `#bug <内容>` | 提交 Bug 报告（附上下文快照） |
| `#建议 <内容>` | 提交改进建议（附上下文快照） |
| `/帮助` 或 `/help` 或 `/命令` | 显示系统命令列表 |

### 群聊

| 命令 | 说明 |
|------|------|
| `/取消` 或 `#取消` | 退出群聊连续对话模式 |

## 权限级别

| 级别 | 角色 | 配置方式 | 区别 |
|------|------|---------|------|
| **管理员** | admin | `SUPERUSERS` 环境变量 | 全部工具（含 shell_exec），代码 60s/100KB，工作区 2GB，特殊会话 10 个 |
| **会员** | vip | `VIP_USERS` 环境变量 | 大部分工具（含 web_fetch / download_repo），代码 15s/50KB，工作区 500MB，特殊会话 3 个 |
| **普通** | regular | 默认 | 基础工具（搜索/天气/地图/文件阅读/娱乐），工作区 100MB，特殊会话 1 个 |
