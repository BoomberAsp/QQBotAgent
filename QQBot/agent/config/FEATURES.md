# 功能一览

本文档列出机器人的全部功能，按大类分组。发送 `/功能` 或 `/features` 即可在 QQ 中直接查看。

---

## AI 对话

| 功能 | 说明 |
|------|------|
| 智能问答 | LLM Agent 驱动，Think → Act → Observe → Respond 循环，最多 20 轮工具调用 |
| 多模型路由 | 简单问题用快速模型，复杂推理用强力模型，图片/音频另有专用模型 |
| 上下文记忆 | 临时会话保留最近 20 条消息，特殊会话持久保存完整历史；长会话可用 /压缩会话 把早期内容浓缩成摘要（保留最近 10 条原文），快装满时我也会主动提醒你 |
| 群聊连续对话 | @机器人一次后 90 秒内可免 @ 继续追问，`/取消` 退出 |
| 人格切换 | 助手Roxy / 角色Roxy / 露比 三种人格 + 你的自创角色，提示词驱动，`/人格切换` 切换；特殊会话创建时绑定当前人格，切换会话自动切回该会话的人格（会话内切换仅作用于本会话，`--全局` 修改默认）；超级用户可 `/toggle personality <名称>` 为群聊绑定默认人格 |
| 双平面路由 | 角色人格下闲聊由角色本人回应，实用任务（搜索/计算/文件/代码）自动委派给助手 Roxy 办理，结果再由角色转述 |

## 角色养成（羁绊系统）

与角色人格（露比、自创角色等）相处时生效，好感记录每人独立。

| 功能 | 说明 | 条件 |
|------|------|------|
| 好感度养成 | 日常聊天积累好感（只增不减），羁绊等级越高角色态度越升温，`/好感度` 随时查看 | 所有人 |
| 自创角色 | `/创建角色` 访谈式创作专属角色（姓名/性格/说话风格/外观），访谈末尾可设定**初始羁绊等级**（Lv1–Lv5，你们故事起点的亲疏，仅对本人生效）；生成后可 `/人格切换` 选用并养成好感；`/删除角色` 管理，仅自己可见 | 按身份配额 |
| 送礼 & 戳一戳 | 对话里说「送你一朵花」即可送礼（送对喜爱之物涨好感更多），QQ「戳一戳」角色会以口吻回应 | 每日有上限 |
| 羁绊档案 | 随羁绊等级提升逐段解锁角色背景档案，角色会在合适的时机自然向你透露更多故事 | 随等级解锁 |
| 剧情场景 | `/剧情` 查看可用场景，`/剧情 <标题>` 进入一对一剧情会话按分幕共同演绎，走到结局获赠「羁绊纪念卡」；**不占特殊会话配额**，完结后自动封档，可随时 `/切换会话` 回看 | 仅私聊 |
| 久别重逢 | 长时间未聊后再对话，角色会流露重逢的喜悦；相识满 30/100/365 天等里程碑时会提及这个特别的日子 | 自动触发 |
| 角色信箱 | 羁绊 Lv5 以上的角色超过一天没和你聊天，会给你写一句留言（≤60 字）；每天最多一封「信封」汇总发到官方单聊，点按钮即可展开，`/邮件` 回看全部来信（保留 28 天）；低频不打扰，QQ 里点「拒收」即停发 | 羁绊 Lv5+，仅官方单聊 |
| 画图 & 语音 | Lv4 起可向角色要图（「画张自拍给我」），Lv5 起可要语音（「用语音跟我说晚安」），形象与声线始终如一；Lv7 以上角色偶尔主动发图/语音 | 每日有上限 |
| 参考立绘 | 把一张图设为自己自创角色的外观基准（`/设形象`），之后画图与主动发图走图生图，面部更稳定；`/形象` 查看、`/清除形象` 撤销。内置人格（露比等）的立绘由管理员统一设置、全局生效 | 自创角色 / 管理员 |
| 影音记忆 | 角色会记住你们之间的图片和语音（含你发给 TA 的），说「再发一次那张图」即可召回；久远影音会留下文字记忆，角色凭记忆向你描述 | 自然语言 |

## 直接命令一览

以下命令**直接由系统处理、不经过智能体**，零 token 消耗。

### 会话管理

| 命令 | 说明 |
|------|------|
| `/新会话 [名称]` | 创建特殊会话（留空自动命名；创建时绑定当前人格） |
| `/切换会话 <名称>` | 切换到已有会话（自动切回该会话绑定的人格） |
| `/会话列表` 或 `/会话` | 查看所有会话（含各会话绑定的人格） |
| `/重命名会话 <旧名> <新名>` | 重命名会话 |
| `/删除会话 <名称>` | 删除会话（60秒内二次确认） |
| `/压缩会话` | 把当前会话早期历史浓缩成摘要，保留最近 10 条原文（60秒内二次确认；仅私聊；剧情/创作会话不支持） |
| `/保存为会话 <名称>` | 将临时对话保存为特殊会话 |
| `/结束会话` 或 `/临时会话` 或 `/退出特殊会话` | 退出特殊会话，回到临时模式 |
| `/clear` 或 `清除上下文` | 清除临时会话上下文 |

### 人格 & 功能

| 命令 | 说明 |
|------|------|
| `/人格切换` 或 `/personality` | 查看当前人格和可用列表（含你的自创角色）与生效来源 |
| `/人格切换 <名称>` | 切换人格（支持模糊匹配，如「露比」「Rubi」）；特殊会话内仅切换本会话绑定的 |
| `/人格切换 <名称> --全局` | 修改你的默认人格（当前会话绑定不变，退出会话后生效） |
| `/功能` 或 `/features` | 查看完整功能一览（本表） |
| `/更新日志 [d]` 或 `/update record [d]` | 查看机器人最近 d 条更新记录（默认 3，最多 20），也可自然语言询问 |
| `/管理工作区` | 查看工作区占用并引导清理 |
| `/status` | 查看机器人运行状态 |

### 角色养成（羁绊）

| 命令 | 说明 |
|------|------|
| `/好感度`、`#好感度` 或 `/bond` | 查看与当前角色的羁绊等级、心情与陪伴统计（需处于启用了养成设定的角色人格下） |
| `/剧情` | 查看与当前角色可体验的剧情场景列表 |
| `/剧情 <标题>` | 进入一对一剧情会话（仅私聊可启动，**不占特殊会话配额**；`/结束会话` 中途退出会保留进度、再发 `/剧情 <同标题>` 可恢复；走到结局自动封档，`/切换会话` 回看） |
| `/创建角色` | 开启访谈式自创角色（回答「跳过」用默认值、「随机」让机器人代拟；末尾可设初始羁绊等级 Lv1–Lv5；占用一个特殊会话槽） |
| `/删除角色 [名称]` | 不带名称查看你的自创角色列表；带名称删除（需回复「确认删除角色 <名称>」二次确认） |
| `/设好感 <等级1-10>` | 把你与当前角色的羁绊直接设到目标等级（可升可降，只作用于你自己） |
| `/设形象 [角色名]` | 把一张图设为自己自创角色的参考立绘（图片+命令一起发，或引用图片后发命令；不带角色名时作用于当前人格）。内置人格仅管理员可改，全局生效 |
| `/形象 [角色名]` | 查看该角色当前的参考立绘（别名 `/查看形象`） |
| `/清除形象 [角色名]` | 清除参考立绘，之后只按文字外观设定作画（别名 `/删形象`） |

## 权限级别

| 级别 | 角色 | 配置方式 | 区别 |
|------|------|---------|------|
| **管理员** | admin | `SUPERUSERS` 环境变量 | 全部工具（含 shell_exec），代码 60s/100KB，工作区 2GB，特殊会话 10 个 |
| **会员** | vip | `VIP_USERS` 环境变量 | 大部分工具（含 web_fetch / download_repo），代码 15s/50KB，工作区 500MB，特殊会话 3 个 |
| **普通** | regular | 默认 | 基础工具（搜索/天气/地图/文件阅读/娱乐），工作区 100MB，特殊会话 1 个 |
