# 帮助 · 命令速查

以下为机器人部分命令，由系统直接处理。完整能力见 `/功能`。

## 使用注意

- 日常临时对话 30 分钟无消息清空上下文，只记最近 20 条
- 想长期连着聊，用 **/新会话** 开一个
- 换话题、换人格前尽量先 **/结束会话**，否则不保证效果
- 日常临时会话里 /人格切换 会改默认人格；只想这次换人格先 /新会话
- 剧情与创作会话内不能换人格（传入 --全局 参数除外）
- 设定写在角色卡里，聊天里说的不保证效果
- 查资料、算数、写代码直接说，会转给任务面；不要贴大段日志
- 发过的图和语音会被记住，不想被记住就别发
- 机器人跟人一样有短中长三期记忆，说的次数越多记得越牢。
- 特殊会话和人格是相互绑定的，切换会话就会切换到对应人格（上一次你 /结束会话 时的人格）
- **/剧情** 仅私聊可用

## 特殊会话管理

- `/新会话 [名称]` — 新建特殊会话，留空自动命名
- `/切换会话 <名称>` — 切换到已有会话
- `/会话列表` 或 `/会话` — 列出所有会话
- `/重命名会话 <旧> <新>` — 重命名
- `/删除会话 <名称>` — 删除（60 秒内确认）
- `/保存为会话 <名称>` — 把当前临时对话存为会话
- `/结束会话` 或 `/临时会话` — 回到临时会话模式

## 人格切换

- `/人格切换` 或 `/personality` — 查看当前人格与可选列表
- `/人格切换 <名称>` — 切换（模糊匹配；特殊会话内仅切换本会话）
- `/人格切换 <名称> --全局` — 修改默认人格（当前会话绑定不变）
- 会话创建时绑定当时人格，切换会话自动切回

## 自创角色（UGC）

- `/创建角色` — 访谈式创建，完成后自动退出（不占配额）
- `/删除角色` 或 `/删除角色 <名称>` — 查看列表 / 删除
- `/设形象 [角色名]` — 设参考立绘：图片+命令或引用图片再发（内置人格仅管理员）
- `/形象 [角色名]` — 查看参考立绘
- `/清除形象 [角色名]` — 清除参考立绘

## 好感度 / 羁绊

- `/好感度` 或 `/bond` — 查看羁绊等级与陪伴统计
- `/设好感 <1-10>` — 直接设定你的羁绊等级
- `/剧情` — 查看可体验的剧情场景
- `/剧情 <标题>` — 进入剧情会话（仅私聊，不占配额；完结自动封档）
- 送礼、戳一戳、主动问候等玩法见 `/功能`

## 游戏工具（Ark Re:Code）

- `/兑换码` — 限时兑换码（含 7 天内过期）
- `/长期兑换码` — 长期有效兑换码
- `/角色详情 <名称>` — 角色面板 / 技能 / 倍率
- `/羁绊详情 <名称>` — 羁绊属性 / 技能 / 获取
- `/刷新角色数据` — 仅管理员：刷新角色/羁绊库

## 群管理（仅群聊 + 超级用户）

- `/toggle` — 查看本群开关与默认人格
- `/toggle <功能> <on|off>` — 开关 gacha / image / voice
- `/toggle personality <名称>` — 设置本群默认人格
- `/取消` 或 `/结束` — 退出连续对话模式

## 反馈

- `#反馈 <内容>` — 提交使用反馈
- `#bug <描述>` — 报 Bug
- `#建议 <内容>` — 提改进建议

## 其他

- `/功能` 或 `/features` — 查看完整功能一览
- `/更新日志 [d]` — 最近 d 条更新（默认 3，最多 20）
- `/status` — 查看机器人运行状态
- `/clear` 或 `新对话` — 清除临时上下文
- `/管理工作区` — 查看工作区占用并引导清理
