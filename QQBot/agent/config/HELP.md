# 帮助 · 命令速查

以下为机器人部分命令，由系统直接处理。完整能力见 `/功能`。

## 使用注意

- 当前模型通常读取本范围最近十轮问答和相关资料；未显示的旧历史不等于已被删除
- 想长期连着聊，用 **/新会话** 开一个
- 想分开话题可用 **/新会话**；不再继续当前具名会话时用 **/结束会话**
- 日常临时会话里 /人格切换 会改默认人格；只想这次换人格先 /新会话
- 剧情与创作会话内不能换人格（传入 --全局 参数除外）
- 设定写在角色卡里，聊天里说的不保证效果
- 查资料、算数、写代码直接说，会转给任务面；不要贴大段日志
- 影音可能另行保存；下面的记忆命令不删除所有图片或语音文件
- 记忆可能出错，可查看、修正或删除；不同角色、群聊与特殊会话的资料不会自动混用
- 特殊会话创建时绑定当时人格，切换会话会切回其绑定人格
- **/剧情** 仅私聊可用

## 特殊会话管理

- `/新会话 [名称]` — 新建特殊会话，留空自动命名
- `/切换会话 <名称>` — 切换到已有会话
- `/会话列表` 或 `/会话` — 列出所有会话
- `/重命名会话 <旧> <新>` — 重命名
- `/删除会话 <名称>` — 删除（60 秒内确认）
- `/压缩会话` — 整理早期历史为分段摘要，新范围保留原文供按需回读（60 秒内确认；仅私聊；剧情/创作会话不支持）
- `/保存为会话 <名称>` — 把当前临时对话存为会话
- `/结束会话` 或 `/临时会话` — 回到临时会话模式

## 记忆管理

以下只作用于当前角色与会话范围；先用“列表”取得记忆 ID。

- `/记忆 列表` — 查看记忆 ID、版本和内容
- `/记忆 历史 <id>` — 查看已失效的旧版本
- `/记忆 修正 <id> <内容>` — 修正事实
- `/记忆 删除 <id>` — 删除该事实及版本，并清理本范围派生上下文和任务状态
- `/记忆 清空 确认` — 清空本范围新框架记忆与派生上下文
- `/记忆 暂停`、`/记忆 恢复` — 停止/恢复新记忆和片段写入；不等于删除已有事实

这些命令不擦除旧档案、任务日志、影音原件、备份或已发送消息。`/clear` 只清工作上下文和任务状态，保留长期事实；更广泛的数据删除请联系运维。

## 人格切换

- `/人格切换` 或 `/personality` — 查看当前人格与可选列表
- `/人格切换 <名称>` — 切换（模糊匹配；特殊会话内仅切换本会话）
- `/人格切换 <名称> --全局` — 修改默认人格（当前会话绑定不变）
- 会话创建时绑定当时人格，切换会话自动切回

## 自创角色（UGC）

- `/创建角色` — 访谈式创建，完成后自动退出（不占配额）
- `/删除角色` 或 `/删除角色 <名称>` — 查看列表 / 删除
- `/设形象 [角色名]` — 设参考立绘：图片+命令或引用图片再发（内置人格仅管理员）
- `/形象 [角色名]` — 查看参考立绘
- `/清除形象 [角色名]` — 清除参考立绘

## 好感度 / 羁绊

- `/好感度` 或 `/bond` — 查看羁绊等级与陪伴统计
- `/设好感 <1-10>` — 直接设定你的羁绊等级
- `/剧情` — 查看可体验的剧情场景
- `/剧情 <标题>` — 进入剧情会话（仅私聊，不占配额；完结自动封档）
- `/邮件` — 角色信箱（仅官方单聊）：列表 / `下一页` / `MM-DD` / 编号看全文
- 送礼、戳一戳、角色来信等玩法见 `/功能`

## 游戏工具（Ark Re:Code）

- `/兑换码` — 限时兑换码（含 7 天内过期）
- `/长期兑换码` — 长期有效兑换码
- `/角色详情 <名称>` — 角色面板 / 技能 / 倍率
- `/羁绊详情 <名称>` — 羁绊属性 / 技能 / 获取
- `/刷新角色数据` — 仅管理员：刷新角色/羁绊库

## 群管理（仅群聊 + 超级用户）

- `/toggle` — 查看本群开关与默认人格
- `/toggle <功能> <on|off>` — 开关 gacha / image / voice
- `/toggle personality <名称>` — 设置本群默认人格
- `/取消` 或 `/结束` — 退出连续对话模式

## 反馈

- `#反馈 <内容>` — 提交使用反馈
- `#bug <描述>` — 报 Bug
- `#建议 <内容>` — 提改进建议

## 其他

- `/功能` 或 `/features` — 查看完整功能一览
- `/更新日志 [d]` — 最近 d 条更新（默认 3，最多 20）
- `/status` — 查看机器人运行状态
- `/clear` 或 `新对话` — 清理工作上下文与任务状态，保留长期事实和人格绑定
- `/管理工作区` — 查看工作区占用并引导清理
- `/免责声明` — 查看免责尾状态；`/免责声明 关` 不再在回复末尾追加免责声明
