# 帮助 · 命令速查

以下命令**直接由系统处理、不经过智能体**，零 token 消耗。发送 `/功能` 查看完整功能一览。

---

## 特殊会话管理

- `/新会话 [名称]` — 创建特殊会话（留空自动命名）
- `/切换会话 <名称>` — 切换到已有会话
- `/会话列表` 或 `/会话` — 查看所有会话
- `/重命名会话 <旧名> <新名>` — 重命名会话
- `/删除会话 <名称>` — 删除会话（需二次确认）
- `/保存为会话 <名称>` — 将临时上下文保存为会话
- `/结束会话` 或 `/临时会话` 或 `/退出特殊会话` — 退出特殊会话

## 工作区

- `/管理工作区` — 查看工作区占用并引导清理

## 人格切换

- `/人格切换` — 查看当前人格和可用列表
- `/人格切换 <名称>` — 切换人格（支持模糊匹配）

## 游戏工具（Ark Re:Code）

- `/兑换码` 或 `/redeem-code` — 查询有效兑换码
- `/角色详情 <名称>` — 查询角色详情（面板/技能/倍率）
- `/羁绊详情 <名称>` — 查询羁绊详情（类别/星级/属性/技能）

## 连续对话（群聊）

- `/取消` 或 `#取消` — 退出连续对话模式

## 反馈

- `#反馈 <内容>` — 提交功能建议
- `#bug <内容>` — 提交 Bug 报告
- `#建议 <内容>` — 提交改进建议

## 其他

- `/功能` 或 `/features` — 查看完整功能一览
- `/status` — 查看机器人运行状态
- `/clear` 或 `新对话` — 清除临时上下文
