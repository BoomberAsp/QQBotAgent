# 帮助 · 命令速查

以下命令由系统直接处理、不经过智能体（零 token）。完整能力清单见 `/功能`。

---

## 特殊会话管理

- `/新会话 [名称]` — 新建特殊会话，留空自动命名
- `/切换会话 <名称>` — 切换到已有会话
- `/会话列表` 或 `/会话` — 列出所有会话
- `/重命名会话 <旧> <新>` — 重命名会话
- `/删除会话 <名称>` — 删除会话（60 秒内二次确认）
- `/保存为会话 <名称>` — 把当前临时对话存为会话
- `/结束会话` 或 `/临时会话` — 回到临时会话模式

## 工作区

- `/管理工作区` — 查看工作区占用并引导清理

## 人格切换

- `/人格切换` 或 `/personality` — 查看当前人格与可选列表
- `/人格切换 <名称>` — 切换人格（支持模糊匹配）

## 自创角色（UGC）

- `/创建角色` — 访谈式创建专属角色，占一个会话槽
- `/删除角色` 或 `/删除角色 <名称>` — 查看列表 / 删除角色
- `/设形象 [角色名]` — 设参考立绘：图片 + 命令，或引用图片再发命令
- `/形象 [角色名]` — 查看参考立绘
- `/清除形象 [角色名]` — 清除参考立绘

## 好感度 / 羁绊

- `/好感度` 或 `/bond` — 查看当前羁绊等级与陪伴统计
- `/设好感 <1-10>` — 直接设定你的羁绊等级
- `/剧情` — 查看可体验的剧情场景
- `/剧情 <标题>` — 进入一对一剧情会话（仅私聊）
- 送礼、戳一戳、主动问候、影音记忆等玩法见 `/功能`

## 游戏工具（Ark Re:Code）

- `/兑换码` — 限时兑换码（含 7 天内刚过期的）
- `/长期兑换码` — 长期有效兑换码
- `/角色详情 <名称>` — 角色面板 / 技能 / 倍率
- `/羁绊详情 <名称>` — 羁绊属性 / 技能 / 获取
- `/刷新角色数据` — 仅管理员：强制刷新角色 / 羁绊库

## 群管理（仅群聊 + 超级用户）

- `/toggle` — 查看本群开关与默认人格
- `/toggle <功能> <on|off>` — 开关 gacha / image / voice
- `/toggle personality <名称>` — 设置本群默认人格

## 连续对话（群聊）

- `/取消` 或 `/结束` — 退出连续对话模式

## 反馈

- `#反馈 <内容>` — 提交使用反馈
- `#bug <描述>` — 提交 Bug 报告
- `#建议 <内容>` — 提交改进建议

## 其他

- `/功能` 或 `/features` — 查看完整功能一览
- `/更新日志 [d]` — 最近 d 条更新（默认 3，最多 20）
- `/status` — 查看机器人运行状态
- `/clear` 或 `新对话` — 清除临时上下文
