# 帮助 · 命令速查

以下命令**直接由系统处理、不经过智能体**，零 token 消耗。发送 `/功能` 查看完整功能一览。

---

## 特殊会话管理

- `/新会话 [名称]` — 创建特殊会话（留空自动命名）
- `/切换会话 <名称>` — 切换到已有会话
- `/会话列表` 或 `/会话` — 查看所有会话
- `/重命名会话 <旧名> <新名>` — 重命名会话
- `/删除会话 <名称>` — 删除会话（需二次确认）
- `/保存为会话 <名称>` — 将临时上下文保存为会话
- `/结束会话` 或 `/临时会话` 或 `/退出特殊会话` — 退出特殊会话

## 工作区

- `/管理工作区` — 查看工作区占用并引导清理

## 人格切换

- `/人格切换` — 查看当前人格和可用列表（含你的自创角色）
- `/人格切换 <名称>` — 切换人格（支持模糊匹配）

## 自创角色（UGC）

- `/创建角色` — 开启访谈式创作：逐项回答角色的姓名、性格、说话风格、外观等设定，收齐后自动生成一个可用 `/人格切换` 选用的专属角色（支持养成好感度）。回答「跳过」用默认值、「随机」让机器人代拟。创建会占用一个特殊会话槽，数量按身份配额（普通 1 / VIP 3 / 管理员 10）
- `/删除角色` — 查看你的自创角色列表
- `/删除角色 <名称>` — 删除某个自创角色（需回复「确认删除角色 <名称>」二次确认；好感度记录会保留）
- 自创角色仅你自己可见、可切换；创建时会自动做安全审查

## 好感度 / 羁绊养成

- `/好感度`、`#好感度` 或 `/bond` — 查看你与当前角色的羁绊等级、心情与陪伴统计（仅在启用了养成设定的角色人格下有效，先用 `/人格切换` 选择角色）
- 与角色日常聊天即可累积好感、提升羁绊等级；等级越高，角色对你的态度与语气会自然升温
- **送礼**：直接在对话里说「送你一朵花」「给你草莓蛋糕」等，角色会收下并按喜好回应（送对喜爱之物涨好感更多）。每天收礼有次数上限
- **戳一戳**：用 QQ 的「戳一戳」戳机器人，角色会以口吻回应你的互动，同样累积好感（每天有次数上限）
- **羁绊档案**：随羁绊等级提升会逐段解锁角色的背景档案，角色会在合适的时机自然向你透露更多故事
- **剧情场景**：羁绊等级达标后解锁专属剧情。发 `/剧情` 查看当前可体验的场景列表，发 `/剧情 <标题>` 与角色进入一对一剧情会话（仅私聊可启动），按分幕共同演绎；走到结局角色会收尾、系统结算好感并送出一张「羁绊纪念卡」。发 `/结束会话` 可提前退出（无完成奖励）。羁绊升级时角色也可能主动邀请你体验新解锁的剧情
- **久别重逢 / 纪念日**：长时间未聊后再次对话，角色会自然流露重逢的喜悦；相识满 30/100/365 天等里程碑时，角色会提及这个特别的日子
- **主动问候**：私聊相识、羁绊达到 Lv5 以上后，若你们已多天没有聊天，角色偶尔会主动发一条私信问候你（低频不打扰：每人数天最多一条、每天至多一条，且受平台主动消息配额约束）
- **画图和语音**：羁绊 Lv4 起可以直接向角色要图（如「画张自拍给我」「画一下我们在海边的样子」），Lv5 起可以让角色用语音说话（如「用语音跟我说晚安」）。角色的形象与声线始终如一；求图/求语音每天有次数上限（按身份分档），超限时角色会温柔婉拒。羁绊 Lv7 以上，角色偶尔还会**主动**发一张图或一段语音给你（每天至多一条，低频不打扰）

## 游戏工具（Ark Re:Code）

- `/兑换码` 或 `/redeem-code` — 查询当前有效的限时兑换码（含 7 天内刚过期的），逐条单发方便复制；数据由管理员人工维护（有效期截至当日 08:00 北京时间）
- `/长期兑换码` — 查询长期有效（无过期时间）的兑换码
- `/角色详情 <名称>` — 查询角色详情（面板/技能/倍率）
- `/羁绊详情 <名称>` — 查询羁绊详情（类别/星级/属性/技能）

## 连续对话（群聊）

- `/取消` 或 `#取消` — 退出连续对话模式

## 反馈

- `#反馈 <内容>` — 提交功能建议
- `#bug <内容>` — 提交 Bug 报告
- `#建议 <内容>` — 提交改进建议

## 其他

- `/功能` 或 `/features` — 查看完整功能一览
- `/更新日志 [d]` 或 `/update record [d]` — 查看机器人最近 d 条更新记录（默认 3，最多 20）；也可直接用自然语言询问「最近有什么更新」
- `/status` — 查看机器人运行状态
- `/clear` 或 `新对话` — 清除临时上下文
